# OGEA-101 — Exam day: time strategy and last-minute sheet (Todo: exam-day)

**Official format reminder:** OGEA-101 — **40** questions, **60** minutes, **closed book**, **60%** pass (**24**/40). Confirm details on [The Open Group certification site](https://certification.opengroup.org) before you sit.

---

## During the exam

1. **Pace:** ~**90 seconds** per question on average; **flag** and move on if stuck **>2 minutes**.  
2. **Reserve** ~**5 minutes** at the end for flagged items only.  
3. **Eliminate** options that **break ADM logic** (e.g., implementation contracts as the main output of Phase A).  
4. **B/C/D split:** Business = **B**, Data/App = **C**, Technology = **D** — wrong domain = wrong answer.  
5. **“Primary / Best / First”** → choose the answer that matches **TOGAF definitions**, not general IT habit.  
6. **Absolutes** (“always,” “never,” “only”) are often **wrong** unless they restate a definition.  
7. **No penalty** for guessing on typical multiple-choice — **do not leave blanks**.  
8. If two answers remain: ask **which phase** or **which definition** the stem is really testing.

## One-page last-minute revision (close book after this)

**ADM order:** Preliminary → A → B → C → D → E → F → G → H  
**Hub:** Requirements Management ↔ **all** phases (continuous)

| Phase | One line |
|-------|----------|
| Preliminary | EA **capability**, governance, principles, frameworks |
| A | **Vision**, stakeholders, approval to proceed |
| B | **Business** baseline/target |
| C | **Data** + **Applications** |
| D | **Technology** baseline/target |
| E | **Work packages**, consolidate gaps |
| F | **Roadmap**, migration timing |
| G | **Contracts**, **compliance**, govern build |
| H | **Change** to architecture, new drivers |

**Viewpoint** = recipe (conventions). **View** = dish (result). **Concern** = stakeholder interest.

**ABB** = logical architecture block. **SBB** = implements ABB.

**Repository (7):** Metamodel · Capability · Landscape · Standards Information Base · Reference Library · Governance Log · Architecture Requirements Repository

**Continuum:** generic → **Organization-Specific**

**E vs F vs G:** E = **what** chunks · F = **when** migrate · G = **police** implementation

## If stuck in the last minute

- Write **ADM** on scrap (if allowed) or visualize it.  
- Map the stem to **one phase** or **one definition**.  
- Pick the option that uses **correct TOGAF vocabulary** for that phase.
